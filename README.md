# Waseem-store
A modern, responsive multi-category e-commerce platform featuring product browsing, search, shopping cart, and order management, built with HTML, CSS, and JavaScript.

متجر إلكتروني تجريبي متعدد الأقسام مبني باستخدام HTML وCSS وJavaScript.

## التشغيل
افتح `index.html` في المتصفح.

## النشر
ارفع الملفات إلى المستودع `waseem-store` ثم فعّل GitHub Pages من Settings → Pages واختر `Deploy from a branch` ثم `main` و`/ (root)`.

> هذه نسخة واجهة أمامية تجريبية. السلة محلية على الجهاز، ولا يوجد دفع أو حفظ طلبات أو إدارة منتجات حقيقية حتى ربط Backend مثل Firebase.
